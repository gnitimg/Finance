# Forecasting and online calibration

The current model is a market-adaptive ensemble. It blends a regularized model, nearest historical regimes, and a short-horizon velocity/acceleration prior over returns, moving-average gaps, breakouts, volatility regimes, intrabar range, close location, volume impulse, candle-color state (consecutive up/down streak and recent up-bar ratio), and candle-shape morphology (body size and dominance, upper and lower shadows, opening gap, inside-bar flag). For A-shares the forming bar is refreshed with the near-live Sina snapshot already fetched for the quote, so the live-edge features and forecast origin reflect the real-time price and volume without extra upstream requests. A-shares and Hong Kong use a shorter two-bar calibration horizon, US listings use three bars, and stablecoins use a peg mean-reversion profile with one daily or five intraday bars. Direct-horizon fits create the visible multi-step forward path. The implementation is inspectable, fast, and independent of LLMs.

Training uses a chronological 60/40 split: the earlier 60% fits the coefficients and the walk covers the most recent 40%, reported both in aggregate and as three consecutive windows so a passing score cannot hide single-regime luck. Every displayed validation pass starts from the training cutoff, then predicts each target before consuming its realized result. This prevents persisted online weights from leaking later validation outcomes back into earlier points. Matured validation results update the live coefficients using decaying-rate online gradient descent, and the latest matured timestamp prevents duplicate feedback accounting.

Training samples use a recency weight so fresh regimes influence the fit more strongly without discarding the longer baseline. The model training context is independent from the visible range: a one-day intraday chart uses up to one month of five-minute bars for calibration, while daily charts use up to five years for listed assets or one year for crypto. The kNN analogue pool and the per-step path fits stay bounded to recent samples so the longer context cannot blow up latency. Component weights adapt from errors that have actually matured. A causal return-shrinkage factor, estimated only from earlier matured predictions, corrects systematic amplitude exaggeration. For `1d/5m`, the visible path starts at the latest actual bar, follows real future timestamps to market close, skips lunch and overnight gaps, and is regenerated when a new bar arrives. Outside that mode it uses the market profile's fixed horizon.

The interface renders actual prices in lime and future estimates in bright violet. Historical free-running forecasts are hidden by default and appear in deep violet only when the user enables the complete prediction trail in Settings. The historical path anchors to an observed price only once, then compounds the returns that were predicted at each origin; it must never reset every displayed point to an older actual price because that creates a misleading shifted copy. Teacher-forced one-shot prices remain available only for evaluation. Never merge, overwrite, or visually imply that a predicted point is observed. Display holdout MAE, directional accuracy, return-signal phase diagnostics, performance versus a no-change baseline, and online update count near the chart. A positive phase value means the return signal led the realized return; a negative value means it lagged. If the holdout model does not beat the no-change baseline with at least 50% directional accuracy, cap calibration confidence below the alert threshold. If validation fails or phase is negative, mark the forecast as non-publishable, reduce the visible forward amplitude to 35%, and exclude it from forecast-triggered alerts.

Limitations: the model does not include fundamentals, order book, corporate actions beyond provider-adjusted series, news embeddings, or transaction costs. Regime changes can invalidate historical calibration quickly.
