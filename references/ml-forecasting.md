# Forecasting and online calibration

Version 14 is a product-adaptive four-component ensemble. It combines regularized return regression, nearest historical regimes, a short-horizon velocity/acceleration prior, and an explicit mean-reversion prior. Component weights are recalculated from matured walk-forward absolute error, direction reliability, and performance against a no-change baseline. Inputs cover returns, moving-average gaps, breakouts, volatility regimes, intrabar range, close location, volume impulse, candle streaks, and candle shape. Standardized inputs are clipped to six standard deviations, component outputs use a causal training-return cap, and online gradients and weights are bounded so a low-variance feature cannot produce an explosive path.

Listed-market forming bars are refreshed with the near-live Sina snapshot already fetched for the quote, keeping the live edge aligned without another upstream request. A-share and Hong Kong equity profiles use a one-bar calibration horizon; US equities and ETFs use three, funds and futures/metals use two, and stablecoins use peg-specific mean reversion with one daily or five intraday bars. Cached East Money main-force flow contributes two causal daily features for A-share, Hong Kong, and US symbols; A-shares can also add current Tencent order-book imbalance. The A-share daily model adds CSI 300 daily return and 20-day momentum plus three industry-board inputs: board daily return, board 20-day momentum, and stock daily return minus board daily return. A date pointer only exposes reference rows on or before each stock bar. Price/volume anomalies and available related-content evidence contribute a capped live-context term. Routine analysis remains Python-only.

Training uses a chronological 60/40 split: the earlier 60% fits the coefficients and the walk covers up to the latest 240 validation samples, reported both in aggregate and as three consecutive windows. Every displayed validation pass starts from the training cutoff, then predicts each target before consuming its realized result. This prevents persisted online weights from leaking later outcomes into earlier points. Matured results update the live coefficients with clipped, decaying-rate online gradients, and the latest matured timestamp prevents duplicate feedback accounting.

Training samples use a recency weight so fresh regimes influence the fit without discarding the longer baseline. Interactive one-day intraday analysis fetches the fast five-day context once and slices the latest exchange-local session for display; the background calibration job can use one month. Daily charts use up to five years for listed assets or one year for crypto. Historical analogue search is bounded to 240 recent samples. For `1d/5m`, at most six direct multi-horizon fits anchor the visible path, with cumulative-return interpolation between anchors; this removes dozens of repeated fits without flattening the forecast. The path starts at the latest actual bar, follows real future timestamps to the session close, skips lunch and overnight gaps, and is regenerated on every new bar. Outside that mode it uses the product profile's fixed horizon.

Sector identity is cached for seven days. Industry-board and CSI 300 daily series use a 30-minute cache and are pre-warmed sequentially by the background trainer; heavy East Money history calls are deferred during A-share pre-open and trading hours. Web asset switching reads these caches only. A direct Hermes CLI analysis may warm its independent cache once; if the provider is unavailable, all corresponding inputs are neutral instead of blocking the remaining analysis or borrowing future data.

The interface renders actual prices in lime and future estimates in bright violet. When the complete prediction trail is enabled in Settings, the deep violet line shows one-shot walk-forward predictions - every point is the model's own forecast made at that bar, anchored at that bar's actual close - so the plot reads as an honest fit view; the free-running compounded path (anchored once) and teacher-forced payloads remain available in the API for evaluation and must never be merged with observed prices. Never merge, overwrite, or visually imply that a predicted point is observed. Display holdout MAE, directional accuracy, return-signal phase diagnostics, performance versus a no-change baseline, and online update count near the chart. A positive phase value means the return signal led the realized return; a negative value means it lagged. If the holdout model does not beat the no-change baseline with at least 50% directional accuracy, cap calibration confidence below the alert threshold. If validation fails or phase is negative, mark the forecast as non-publishable, reduce the visible forward amplitude to 35%, and exclude it from forecast-triggered alerts.

Limitations: the forecast does not include full fundamental statements, a complete cross-market order book, news embeddings, or transaction costs. Related headlines are evidence, not proof of causality. Regime changes can invalidate historical calibration quickly, so a failed no-change or phase-lag gate remains visible and cannot trigger a forecast alert.
